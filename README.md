# 상영 규모와 상영 방식에 따른 영화 흥행 요인 분석

영화를 개봉 규모와 상영 기간으로 군집화하고, 군집마다 흥행 요인이 어떻게 다른지 회귀로 살펴본 수업 팀 프로젝트입니다.

- 과목: 경희대학교 빅데이터애널리틱스 (2024년 2학기, A조)
- 기간: 2024.11 ~ 2024.12
- 팀: 김소륜, 김도균, 송정현, 이채영, 전우빈 (5인)

## 분석 흐름

1. 탐색적 분석과 선행연구 검토
2. 개봉일 상영 횟수(규모)와 상영 기간으로 영화 409편을 4개 군집으로 분류
3. 전체와 군집별로 누적 매출액·수익성에 대한 OLS 회귀

## 결과 요약

| 군집 | 편수 |
|---|---|
| 와이드 장기 | 88 |
| 와이드 단기 | 202 |
| 내로우 장기 | 21 |
| 내로우 단기 | 98 |

- 전체 회귀의 R²는 누적 매출액 0.759, 수익성 0.338이었습니다.
- 수익성 모형에서는 1주차 실관람객 평점의 영향이 커지고 스크린 점유율의 영향은 줄었습니다.
- 내로우 장기 군집은 21편뿐이라 해석하지 않았습니다.

## 내 역할 (김소륜)

- 선행연구 조사와 변수 후보 정리
- 네이버 검색량 변화 비율 변수 가공, 수익성·드랍률·검색량 변수를 합친 분석용 데이터 제작
- 수익성 상관분석과 군집별 상관분석 (군집화 코드는 김도균 작성분을 사용)
- 발표 자료의 변수 선택·전처리 파트와 서론
